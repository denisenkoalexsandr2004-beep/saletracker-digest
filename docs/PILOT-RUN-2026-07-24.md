## Что не входило в этот прогон

- реальная отправка в Telegram;
- сохранение подписчика и редакторских действий в PostgreSQL;
- автоматический запуск в понедельник или четверг;
- автоматический сбор новостей из внешних источников;
- создание AI-черновика и его редакторское утверждение;
- сохранение кликов и лидов ЦЗС в базе.

На момент первоначального демопрогона Telegram-бот ещё не был подключён.
Следующий раздел фиксирует повторение сценария уже с фактической доставкой.

## Сценарий презентации после доработки очереди

Текущая версия разделяет подключение подписчика и отправку выпуска:

1. На главной странице подписчик выбирает роль, темы, периодичность и объём
   выпуска: 5, 10 или 15 новостей. В пилоте доступ бесплатный.
2. После отправки формы система создаёт персональный выпуск со статусом
   «Ждём Telegram».
3. Подписчик открывает персональную ссылку и нажимает Start в Telegram.
4. Локальный сервер автоматически проверяет Start в фоне, даже если
   пользователь вернулся из браузера в Telegram; на публичном сервере
   обновление получает webhook.
5. Бот отправляет приветствие и сразу доставляет первый выпуск. В админке
   сохраняется пользователь, состав и статус отправки.
6. Бот сначала отправляет отдельное приветствие с датой и составом выпуска,
   затем 2–3 сообщения с целыми новостями. Ссылки «Подробнее»
   ведут прямо на оригинальные статьи первоисточников, блок ЦЗС размещается в
   конце.
7. Повторный Start после успешной отправки не создаёт дубликат.

Автоматические проверки новой версии: 26 тестов, production build, desktop и
mobile visual smoke. Для открытия статей с телефона требуется публичный
HTTPS-адрес приложения; `localhost` доступен только на компьютере, где запущен
проект.
