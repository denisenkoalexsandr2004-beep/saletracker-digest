# SaleTracker / Дайджесты

Первый рабочий вертикальный прототип сервиса персональных отраслевых
дайджестов для поставщиков и закупщиков розничных сетей.

Пользовательское название продукта и Telegram-бота — **«Дайджест Платформы
Сейл Трекер»**. ЦЗС является ядром коммерческого маршрута: связывает интерес
подписчика с мероприятиями, переговорами и лидами.

## Что уже работает

- бесплатная публичная настройка роли, тегов, периодичности и объёма;
- ежедневный, двухразовый, еженедельный и ежемесячный ритм;
- выбор объёма выпуска: 5, 10 или 15 новостей;
- API создания подписки с персональной ссылкой на Telegram или демовыпуск;
- привязка Telegram через персональный `/start`-токен и автоматическая
  отправка первого выпуска;
- защищённый webhook и автоматический фоновый polling для локальной пилотной
  отправки;
- команды бота `/digest`, `/settings` и `/help`;
- подборка только из утверждённых материалов после прошлого выпуска;
- исследовательский AI-агент с web search по белому списку доменов;
- очередь AI-кандидатов: прямая ссылка, цифры, значение для бизнеса и обязательная
  редакторская проверка;
- правило 80% точных тегов / 20% общерыночных новостей без искусственной
  добивки;
- Telegram-превью с выделенным блоком цифр, практическим выводом, прямой
  ссылкой «Подробнее» на статью первоисточника и делением между целыми
  новостями;
- CTA на подходящее мероприятие Центра Закупок Сетей только в последнем
  сообщении;
- публичные SEO-страницы блога с некликабельной строкой источников;
- админка с разделением по пользователям, точным составом каждого выпуска,
  ссылками на статьи/первоисточники, реестром источников и AI-сбором.
- PostgreSQL/Drizzle-репозитории для подписок, Telegram, AI-кандидатов,
  выпусков и фоновых заданий; без `DATABASE_URL` включается явный локальный
  деморежим;
- защищённая httpOnly-сессия редактора и закрытые admin API;
- идемпотентные cron-маршруты автономного AI-сбора и рассылки с retry и
  dead-letter после трёх попыток.
- постоянная редакционная база: AI-кандидат передаётся в `review`, редакторское
  утверждение сохраняется, и только `approved`-материалы входят в новые выпуски.

Демонстрационный выпуск собран на открытых публикациях с прямыми
первоисточниками; тексты страниц SaleTracker являются отдельным аналитическим
слоем. Реальные контакты пользователей в репозиторий не включены.

## Локальный запуск

Нужен Node.js 24 LTS и npm.

```bash
npm install
cp .env.example .env.local
npm run dev
```

После запуска:

- `http://localhost:3000` — публичная страница;
- `http://localhost:3000/preview` — пример Telegram-выпуска;
- `http://localhost:3000/admin` — редакторская админка;
- `http://localhost:3000/api/health` — состояние сервиса;
- `http://localhost:3000/api/ready` — готовность базы и авторизации;
- `http://localhost:3000/api/telegram/status` — состояние Telegram;
- `http://localhost:3000/api/admin/news-candidates` — очередь AI-кандидатов.

## Проверка

```bash
npm test
npm run lint
npm run build
```

При запущенном локальном сервере `npm run visual:check` проверяет три ключевые
страницы в desktop/mobile, основной сценарий формы, состав выпуска и фильтр
админки. Скриншоты сохраняются локально в `artifacts/visual`.

## Переменные окружения

Скопируйте `.env.example` в `.env.local`. Без `TELEGRAM_BOT_USERNAME` форма
возвращает ссылку на демовыпуск. Без `OPENAI_API_KEY` Telegram-пилот и
редакторские демоданные работают, но кнопка сбора реальных новостей объясняет,
какой ключ нужно добавить. Секреты не должны попадать в git.

## Граница текущей версии

Без `DATABASE_URL` это проверяемый локальный срез продукта: данные сохраняются
только в памяти. При подключённом PostgreSQL подписки, Telegram-аккаунты,
AI-кандидаты, доставки и задания сохраняются между перезапусками. Следующий
production-этап — claim-level проверка фактов и автоматический green/yellow/red
контроль достоверности. План описан в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md), а запуск
инфраструктуры — в [docs/PRODUCTION-SETUP.md](docs/PRODUCTION-SETUP.md). Методика и исследованный реестр
источников — в
[docs/NEWS-SOURCES-AND-AI.md](docs/NEWS-SOURCES-AND-AI.md).

Пошаговое создание и подключение бота описано в
[docs/TELEGRAM-SETUP.md](docs/TELEGRAM-SETUP.md).
